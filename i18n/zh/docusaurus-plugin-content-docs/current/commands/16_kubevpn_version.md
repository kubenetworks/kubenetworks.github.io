# kubevpn version

打印客户端版本信息。

## 示例

```shell
kubevpn version
```

```text
KubeVPN: CLI
    Version: v2.3.0
    Daemon: v2.3.0
    Image: ghcr.io/kubenetworks/kubevpn:v2.3.0
    Branch: master
    Git commit: ac918b5
    Built time: 2024-09-03 20:31:08
    Built OS/Arch: darwin/arm64
    Built Go version: go1.22.6
```

`kubevpn version` 没有任何选项；它打印客户端、守护进程与镜像版本。
