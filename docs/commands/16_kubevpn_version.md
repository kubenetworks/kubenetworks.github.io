# Kubevpn version

Print the client version information.

## Example

```shell
kubevpn version
```

```text
KubeVPN: CLI
    Version: v2.11.5
    Daemon: v2.11.5
    Image: ghcr.io/kubenetworks/kubevpn:v2.11.5
    Branch: master
    Git commit: ac918b5
    Built time: 2024-09-03 20:31:08
    Built OS/Arch: darwin/arm64
    Built Go version: go1.22.6
```

`kubevpn version` takes no options; it prints the client, daemon, and image versions.
